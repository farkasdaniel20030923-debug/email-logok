# email-logok

Nyilvános logók a **WGSZ** és a **DÉFCS** levélszerkesztőhöz.

A Gmail törli a levélbe ágyazott képeket, ezért a levelek fejlécében lévő logók innen töltődnek be.

| Fájl | Hol jelenik meg |
|---|---|
| `wgsz-logo.png` | WGSZ levél fejléce (fehér logó) |
| `wgsz-sze-logo.png` | WGSZ fejléc – Széchenyi István Egyetem logó (ha be van kapcsolva) |
| `defcs-ikon.png` | DÉFCS levél fejléce – ikon |
| `defcs-felirat-vilagos.png` | DÉFCS felirat sötét fejléchez |
| `defcs-felirat-sotet.png` | DÉFCS felirat világos fejléchez |

**Fontos:** a repó maradjon nyilvános, és a fájlokat ne nevezd át, ne helyezd át és ne töröld – a már elküldött levelek is ezekre a címekre hivatkoznak. Logócsere esetén a fájlt azonos néven írd felül.
